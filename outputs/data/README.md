# Data directory

This publication snapshot does not include a full raw workload-backend pair dataset in this directory.

The committed open-science package focuses on reviewed summary tables, validation artifacts, metadata anchors/comparisons, and figures. Dataset dimensions and aggregate characteristics are available in `../tables/final_dataset_description.csv`.

If a future release publishes raw or derived datasets here, each file should include provenance, generation parameters, license/redistribution status, and a checksum in `../SHA256SUMS.txt`.
